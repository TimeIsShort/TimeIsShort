## 01 · Featured Projects 精选项目

### 🧠 Private RAG — 面向复盘与治理的 AI 知识治理平台（私有项目，正在开发）

**为什么做它：** 实际维护十几个微服务时，每次排障、复盘都要重复提供业务背景、跨服务追踪缺陷，成本很高。

**真实演进路线：**

- 先在本地知识库验证效果：把缺陷修复经验、项目知识、MCP 检索与人工审核连接起来
- 再迁移到云端 Qdrant，继续完善权限、审核和知识治理
- 当前重点：投递审核、候选核对、差异对照、治理工作台

**技术栈：** Vue 3 + TypeScript + Spring Boot · Qdrant · MCP

> 注：这是私有项目，仓库不公开。上面描述的是已验证的演进路线，不是目标架构宣传。
